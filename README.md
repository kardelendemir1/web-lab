# Web Tasarımı ve Programlama LAB-1

Bu proje Web Tasarımı ve Programlama dersi LAB-1 ödevi kapsamında oluşturulmuştur.
Modern web geliştirme ortamının temellerini (Node.js, npm, Vite, React, TypeScript ve Git) pratik olarak uygulamak amacıyla hazırlanmıştır.

## Kullanılan Teknolojiler

- Vite
- React
- TypeScript
- CSS
- Git & GitHub

## Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

1. Proje dizininde terminal açın.
2. Gerekli bağımlılıkları yüklemek için aşağıdaki komutu çalıştırın:
   ```bash
   npm install
   ```
3. Geliştirme sunucusunu başlatmak için şu komutu kullanın:
   ```bash
   npm run dev
   ```
4. Terminalde belirtilen yerel adresi (genellikle http://localhost:5173) tarayıcınızda açın.
